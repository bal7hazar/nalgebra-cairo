## 1. Goal

Reduce the net Cairo steps of the four probes whose code is generated by `tools/shapegen` (docs/STEPS.md, main):
`matrix3_mul` 186, `matrix3_try_inverse` 430, `matrix3_determinant` 82, `matrix6_mul_vec` 192 — by changing the
**generator** (`tools/shapegen/**`), so every generated shape benefits; then regenerate with
`python3 tools/shapegen/shapegen.py` and commit **every regenerated file** (the `--check` mode must pass).
OPT-1 (#102) and OPT-2 (#103) are the model: inlining (`#[inline(always)]` on methods of impls), removing redundant
work, reusing sub-terms, avoiding `Option` round-trips — only where the result is the same bits for every input.

**Bit-identical is the hard rule.** A change that alters rounding (e.g. a fused kernel replacing separate roundings)
is a numeric change: do not make it; list it as a proposal with its expected steps saved. A fused kernel `fixed` lacks
is never written here: list it under Escalations.

## 2. Results shown unchanged

- Every existing test, golden, oracle vector and probe assertion passes with no test edited.
- Equivalence sweeps: for each generated function whose body changes (not only an attribute), keep the previous body

  file) and compare old and new bit for bit on 200+ inputs per function (edge cases: zero, identity, singular, extreme
  Q32.32 magnitudes, signs) — at least for the dimensions of the four probes; say how the other dimensions are covered.
