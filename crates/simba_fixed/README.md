# simba_fixed

`simba::Real` and `simba::Transcendental` for **glam.cairo's** `fixed::Fixed`, so the provable
physics stack can use nalgebra.cairo's types with the scalar it already has.

```toml
[dependencies]
nalgebra = { git = "https://github.com/bal7hazar/nalgebra.cairo" }
simba_fixed = { git = "https://github.com/bal7hazar/nalgebra.cairo" }
fixed = { git = "https://github.com/bal7hazar/glam.cairo" }
```

```cairo
use fixed::Fixed;
use nalgebra::Vector3;
use nalgebra::base::vector3::Vector3Trait;
use simba_fixed::prelude::*;

let v = Vector3 { x: Real::from_int(3), y: Real::from_int(-4), z: Real::<Fixed>::ZERO };
assert!(v.norm() == Real::from_int(5));
```

## How it works

Both scalars are `struct { raw: i64 }` in Q32.32 with floor rounding, so a conversion is a pure
relabelling (`to_simba` / `from_simba`, and `Into` both ways). `FixedReal` converts and calls
**simba's own kernels** — nothing is reimplemented — so nalgebra computes the same raw values
whichever scalar it is instantiated with, and the conversion costs nothing:

| group | `via_fixed` (net gas) | `via_simba` (net gas) |
|---|---:|---:|
| `convert` round trip | 0 | — |
| `sum_prod3` | 2,150 | 2,150 |
| `norm3` | 2,220 | 2,220 |

`FixedTranscendental` is the deliberate exception: `sin`, `cos`, `sin_cos`, `tan`, `asin`, `acos`,
`atan` and `atan2` forward to glam.cairo's `TrigTrait`, so a rotation built by glam.cairo and one
built by nalgebra.cairo agree bit for bit. `exp` and `ln` are simba's (glam.cairo has neither).

## Known differences

Measured case by case in `src/conformance.cairo`, asserted rather than tolerated:

| operation | difference |
|---|---|
| glam.cairo's own `/`, `%`, `FixedTrait::recip` | glam.cairo truncates toward zero, simba floors: one ulp apart on negative inexact results. This concerns the scalar's operators only: nalgebra divides through `Real::div` / `Real::rem`, which are simba's floor kernels here, so `normalize`, `new_normalize`, `unscale`, the inverses and the decompositions are bit-identical and panic with `'simba: division by zero'`. Everything routed through `Real` (every fused kernel, `div`, `rem`, `recip`, `sqrt`, `inv_sqrt`) is bit-identical. |
| `FixedTrait::signum(0)` | glam.cairo gives `+1`, simba `0`. `Real::signum` is simba's. |
| constants | `Real::<Fixed>::PI` and friends are simba's floored values so that formulas match; `fixed::PI` rounds to nearest. Seven of the twenty differ by one ulp. |
| trigonometry | two different generated polynomials, a few ulp apart; both inside the oracle tolerances. glam.cairo's `sin_cos` costs 31,400 gas against simba's 17,220. `asin` / `acos` out of domain panic with `'Fixed: asin domain'` / `'Fixed: acos domain'`. |

## Tests

- `src/conformance.cairo` — the two scalars operand by operand, on the tables generated by
  `tools/gen_vectors.py` (fixed seed, every magnitude class) and on the oracle vectors of
  `src/oracle_scalar.cairo`.
- `tests/test_nalgebra_types.cairo` — `Vector3`, `SymMatrix3`, `UnitQuaternion` and `Isometry3`
  computed with both scalars, compared raw by raw.
- `src/benches.cairo` — `bench_simba_fixed_<op>__{via_fixed,via_simba}`, snapshot in
  `gas/simba_fixed.md`.
